# Прогресс обучения NestJS и PostgreSQL

Учебный проект — API интернет-магазина на NestJS с прямыми SQL-запросами через `pg`. Используем существующую локальную базу `learning` и схему `shop`. API каталога готов. Следующий этап — регистрация пользователей.

Фронтенд и его проверки ведёт ассистент. Реализация NestJS остаётся учебной практикой.

## Сделано

- [x] В PostgreSQL спроектированы и созданы восемь таблиц магазина. Фактическая схема `shop` подтверждена.
- [x] NestJS подключён к `learning` через общий `pg.Pool`. Настройки берутся из окружения, `start:dev` загружает локальный `.env`.
- [x] Проверены запрос при запуске и закрытие пула при остановке приложения через `app.close()` и `Ctrl+C`.
- [x] Работает `GET /products`. Контроллер, сервис каталога и сервис БД связаны через DI. Эндпоинт возвращает JSON-массив активных товаров с полями `id`, `name`, `price`, `stock`.
- [x] Работает `GET /products/:id`. Проверены JSON-объект товара, `400` для некорректного ID и `404` для отсутствующего товара. Параметр передаётся через `$1`, общий пайп проверяет положительные безопасные целые числа, а тип ответа описывает `id` и `price` как строки.
- [x] Работает `POST /products`. Через форму и временные таблицы PostgreSQL проверены `201` с созданным объектом и `400` для невалидного тела или отсутствующей категории. Неожиданная ошибка запроса возвращает `500`.
- [x] Работает `PATCH /products/:id`. На временных таблицах проверены частичное обновление, сохранение пропущенных полей, `stock: 0`, `description: null`, ответы `400` и `404`.
